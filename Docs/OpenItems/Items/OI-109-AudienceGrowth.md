# OI-109: Tune long-term audience behavior

- **Type:** Question
- **Status:** Open
- **Area:** Audience
- **Issue:** Choose starting group sizes, shares and loyalty; impression and loyalty scales, resets and update order; formulas for recruitment, churn, regular conversion and return. Define effects of outfits, promotion, replies, missed important questions and game events, repeat decay/reset, and how image changes over time. Iteration 2 values are a per-stream baseline.
- **Return trigger:** When adding persistent audience or changing audience balance.
- **Close when:** Document the long-term model and validate understandable causes and meaningful differences across groups.
