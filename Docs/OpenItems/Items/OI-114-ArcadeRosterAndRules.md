# OI-114: Choose expanded arcade rules and rollout

- **Type:** Proposal
- **Status:** Open
- **Area:** Arcades
- **Issue:** Compare stage-based Snake (food target opens an exit; transition creates a natural break) with current endless attempts. Specify Space Invaders enemies and waves, optional boss, bonus targets and power-ups. Decide 2D arcade versus 3D runner for lane racing, camera, rendering, lane count, speed, collisions, checkpoints and a fixed finish. Racing proposals: automatic forward motion, few lanes, sections of varying obstacle density with calmer breaks, and optional bonuses that make changing lanes a risk. Define goals, failure, retry recovery, difficulty, initial availability, unlocks, rollout order and prototype scope.
- **Return trigger:** When planning the next arcade or revising Snake.
- **Close when:** Approve per-arcade scope after focused prototypes and record initial arcade availability and rollout order.
