# OI-115: Define and validate skill progression

- **Type:** Question
- **Status:** Open
- **Area:** Skills
- **Issue:** Set starting levels, prices, thresholds and practical training criteria, including interaction counts and early exits. Choose arcade mastery tools (e.g. shield charge in the space shooter, collision rescue to a safe state in Snake, extra defensive use in wave-based games), fatigue interactions, psychology hint depth by level and the optional small positive-response hypothesis, and artistry visuals. Compare active help and safeguards, test progression and percentage bonuses; define max-level UI without extra levels or hidden buffs.
- **Return trigger:** When prototyping training and stream practice.
- **Close when:** Document approved abilities and practice criteria and verify progression, balance and the level-4 boundary.
